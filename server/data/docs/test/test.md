# React Hooks

React Hooks 是 React 16.8 引入的新特性。

它允许函数组件拥有状态和生命周期能力。

## useState

useState 用于给函数组件添加状态。

调用 useState 会返回一个数组。

第一个元素是状态值。

第二个元素是更新状态的方法。

### 示例

```js
const [count, setCount] = useState(0)
  console.log('这里是代码块的部分')
```

## useEffect

useEffect 用于处理副作用。

例如：

- 请求接口
- 操作 DOM
- 订阅事件

当依赖数组变化时会重新执行。
